# spam_message_classifier
A Machine Learning based web application that classifies text messages as **Spam** or **Ham (Not Spam)** using Natural Language Processing (NLP) techniques and the **Multinomial Naive Bayes** algorithm.
The project includes complete text preprocessing, feature extraction using TF-IDF Vectorization, model training, evaluation, and deployment through a live interactive web application.

Live app:
https://spammessageclassifier-kqkcxcmgfftj8xbksejc4b.streamlit.app/

Project Overview:
Spam messages are one of the most common problems in digital communication. This project aims to automatically detect whether a message is spam or genuine.The model was trained on SMS message datasets and tested using multiple machine learning algorithms. After comparing performance metrics, the Multinomial Naive Bayes classifier achieved the best results.

Features:
- Detects Spam and Ham messages instantly
- User-friendly web interface
- NLP-based text preprocessing
- TF-IDF vectorization
- High accuracy and precision
- Real-time prediction system
- Live deployed application
